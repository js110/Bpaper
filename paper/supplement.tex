\section{Extended observation-channel example}
For a predicted belief $b=(0.2,0.2,0.2,0.4)$, task region $S=\{1,2,3\}$, availability $\alpha=0.9$, and local cap $c=0.4$, the truthful report posterior has peak $1/3$, so a success-only check would permit full participation. If $q=1$, however, silence leaves the fourth state with posterior probability $0.4/(1-0.9\times0.6)\approx0.870$, violating the cap. BSP therefore rejects this task under the two-branch constraint. The example isolates the role of probabilistic silence without using simulator ground truth.

\section{Comparator adaptations and validation}
\subsection{Pointwise maximal leakage task channel}
Let $l_i=\Pr(Y=1\mid X=i)$ and $m=\sum_i b_i l_i$, with $0\le l_i\le\alpha\mathbf{1}\{i\in S\}$. The task-channel PML specialization maximizes report probability subject to the published pointwise leakage inequalities $l_i\le e^\epsilon m$ and $1-l_i\le e^\epsilon(1-m)$ for every state with positive prior mass~\cite{pml2024}. The implementation is checked against a general linear program over randomized instances. This is a channel specialization, not a reproduction of every component of the original application.
\subsection{PRIVIC task adapter}
PRIVIC learns a noisy location channel through Blahut--Arimoto and incremental Bayesian updates~\cite{privic2024}. We check our BA/IBU/GIBU updates against the authors' public implementation. The task adapter emits a truthful report only when the true state is eligible and the location-channel outcome satisfies the task predicate. Because this changes the output semantics, PRIVIC-T does not inherit the original geo-indistinguishability guarantee. Offline channel fitting is excluded from online gate timing.
\subsection{Per-output KL comparator}
The Bayesian-privacy comparator constrains each positive-probability posterior using $D_{\mathrm{KL}}(b^y\|b)\le\kappa$~\cite{bayesian}. The successful-report divergence is fixed by the task support; the silence bound is solved by bisection. It is a per-output diagnostic rather than a cumulative session guarantee.

\section{Finite-model robustness stress}
The hand-grid ambiguity set uses $v\in\{0.05,0.3,0.8\}$ and $\alpha\in\{0.3,0.648,0.9\}$. Twenty new synthetic seeds, four users per seed, and 48 slots yield 80 trajectories per row at a fixed operating point. When the informed attacker's exact generating model is contained in the set, R-BSP records no local-cap violation in the five reported conditions, as expected from the finite-set construction, while retaining about 39.7\% of externally completable normal-task opportunities.

\section{Data-driven ambiguity construction}
The replay ambiguity set is built without using the \GeoTestN{} isolated test windows. \GeoDevN{} development windows define a coarsened reflecting-walk likelihood $\Pr(\mathrm{change}\mid i)=v d_i/4$ and a development-only smoothed population prior; only change versus no-change events enter this likelihood, not destination direction or jump distance. Two thousand unique-path development bootstraps produce mobility candidates, and 2,000 unique-path validation bootstraps select the smallest set covering at least 95\% of predictive-likelihood winners. The five most frequent population-prior candidates account for 91.25\% of validation-bootstrap winners, so all six candidates are retained, giving 100\% achieved support in this finite candidate set. The development MLE is \GeoDevMLE{} with a 95\% bootstrap interval \GeoDevCILow--\GeoDevCIHigh{}; the validation point estimate is \GeoValMLE{}. Availability remains externally specified because GeoLife contains trajectories rather than task-delivery, willingness, or deadline logs.
A validation-best single-model BSP control separates improved model fit from finite-set robustness. Under the stronger replay attacker, its local-cap violation rate is \GeoSingleLocal\%, compared with \GeoStrictLocal\% observed local-cap violations for strict data-driven R-BSP, but the latter retains only \GeoStrictRet\% of opportunities.

\section{Asymmetric disclosure-floor frontier}
DF-BSP relaxes only the truthful report branch. Reports use $c^+_{\mathrm{DF}}=\max\{\tau,\|b\|_\infty\}$ while silence retains $c^-_{\mathrm{DF}}=\max\{\rho,\|b\|_\infty\}$. At $\tau=\rho$ the rule reduces exactly to BSP. Randomized tests check report admissibility, strict silence feasibility, robust member-wise intersection, and scalar maximality.
On new synthetic walks, $\tau=0.5$ raises 1--8-cell retention from zero to 56.4\% and inverse-area-weighted retention from 12.3\% to 43.1\%, with no observed declared branch-cap violation. In the stronger GeoLife replay, non-robust DF-BSP has a \GeoDFBranch\% branch-cap violation rate at the same $\tau$, whereas data-driven RDF-BSP reduces it to \GeoRDFBranch\% while retaining \GeoRDFSmall\% of small-region opportunities and \GeoRDFWeighted\% inverse-area-weighted utility. The original BSP local cap is violated on \GeoRDFLocal\% of slots because the relaxed report-side threshold can permit greater posterior concentration on truthful reports.

\section{Reproducibility record}
The repository stores deterministic preprocessing, split manifests, configuration files, seeds, event-level compressed logs, trajectory-level summaries, bootstrap outputs, and provenance records. The current automated suite contains 30 tests covering nominal, robust, and disclosure-floor posterior branches; gate reductions and maximality; informed-attacker integration; transition conservation; GeoLife split/missing-minute handling; numerical replay; PML linear-program checks; PRIVIC author-code checks; and policy-envelope optimization.
The effective GeoLife analysis split contains \GeoDevN{} development, \GeoValN{} validation, and \GeoTestN{} test windows after model-input group isolation; user IDs and complete discrete state-path fingerprints are disjoint across these effective splits. The data-driven extension is nevertheless labelled post-hoc because the test replay had already been inspected earlier in the project. No mobile-device energy measurement, production MCS task log, or independent external reproduction is claimed.
